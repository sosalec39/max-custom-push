# MAX пуши

Страница-приёмник уведомлений MAX для iOS-приложения MAX Custom.

MAX присылает Web Push так же, как для web.max.ru на iPhone. Страница добавляется на экран «Домой» (iOS 16.4+), подписывается с публичным VAPID-ключом MAX и передаёт подписку в приложение, а приложение регистрирует её в MAX. Переписку страница не видит: она только показывает уведомления, которые присылает сервер MAX.
